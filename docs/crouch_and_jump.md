# 蹲姿、蹲跳与玩法效果

按住 S / ↓ 只能在地面或平台上蹲下。蹲姿身体轮廓底部（包括描边）对齐角色实际落脚点，收起腿也不会悬空；起跳立即恢复站姿。处于上升、下降、跳跃顶点、走出平台或落地前，物理与视觉均拒绝进入蹲姿。保持蹲键时，落地后可以再次蹲下。下蹲会停止水平移动，但保留仍按住的方向键，起跳后可以继续横移。

## 移动参数

参数在 `data/player_movement_config.gd/.tres`，由大厅、后院、泡泡比赛、弗纳克球比赛、房主裁定和客户端预测共用。

| 参数 | 当前值 |
| --- | --- |
| 普通第一跳、二段跳初速 | 820 |
| 下蹲准备后的第一跳初速 | 940 |
| 松开蹲键后的准备有效期 | 0.18 秒 |
| 重力 | 2200 |

按连续物理公式，普通单跳高度约 153，蹲跳高度约 201；固定物理步长下结果略有差异。蹲着直接起跳也有效，无须松开蹲键。准备加成只能在着地时使用；二段跳恢复普通初速，不继承蹲跳标记，落地清除本次蹲跳状态。窗口按物理时间推进，不能通过空中蹲键重新获得加成。

## 弗纳克球

在加强的第一跳上升过程中接触球，`ball_rules.gd` 根据 `jump_boosted` 和跳跃次数额外添加 160 向上速度；特殊击球最高总速度 760，普通击球保持原有 620 上限。落下时、二段跳时和站立接球不触发额外抬高。

## 吹泡泡

泡泡蓄力上限为 1.5～4.0 秒。`bubble_config.tres` 中的 `crouch_blow_rate=0.7`：蹲着时自然蓄力速度减少 30%，按蹲姿持续时间逐段积分，站起后立即恢复正常速度。`crouch_whistle_multiplier=0.6`：蹲姿目标受到的口哨蓄力增量减少 40%，口哨贡献和击破奖励也按照实际减弱后的增量计算。口哨基础蓄力由 0.11/0.03 增加 20% 至 0.132/0.036（近/远距离），计分奖励再乘 1.2。

吹泡泡期间记录姿势变化时刻，按每段的实际倍率累计自然蓄力；站起、蹲下或起跳不会把过去已吹的时间按新倍率重算。延迟到达的松开输入按其对应时刻计算，暂停期间不累计蓄力，恢复检查点保留姿势时间段。0.3 秒有效吹气下限继续使用真实按住时长；计分风险进度、完美阈值、爆裂判断、环形/条形进度和角色泡泡大小使用折算后的有效蓄力。口哨不虚构吹气时长。

联机快照同步着地状态、蹲跳标记和蓄力姿势倍率。客户端预测与房主裁定必须以相同顺序处理蹲姿和跳跃；新增移动或蓄力字段时，见 [联机协议注意事项](network_protocol.md)。
