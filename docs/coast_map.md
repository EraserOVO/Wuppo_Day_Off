# 海岛比赛地图

泡泡比赛使用原创海岛背景：连续沙丘、三处单向木平台、棕榈、灌木、火把和海浪。角色可从平台下方向上穿过，落下时站在平台上，走出边缘后继续下落；地图没有落水惩罚。

比赛世界以 1920×1080 为基准。绘制位置与可玩地形应保持一致：`ui/stage_background.gd` 绘制背景，`core/player_motion.gd` 提供沙丘和平台落点，`core/world_layout.gd` 管理地图边界与缩放。

角色根节点位于脚底，角色及帽子按相同世界缩放呈现。泡泡、嘴部挂点与角色旋转由皮肤资源和角色视觉脚本管理；替换素材后应检查左右朝向、平台落点和二段跳表现。
