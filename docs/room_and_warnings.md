# 蓄力提示与房间状态

## 蓄力阶段

泡泡按本颗随机时限计算蓄力进度。画面和本机持续提示音随阶段变化：

| 进度 | 表现 |
| --- | --- |
| 低于 50% | 常规蓄力显示 |
| 50%–72% | 黄色提示、轻微抖动和提示音 |
| 72%–88% | 橙色提示和更明显的动画 |
| 88% 以上 | 红色闪烁和快速动画 |

游戏界面不显示“危险”或“即将爆裂”等文字。远端蓄力动画可以短暂平滑外推；预计得分只是显示估算。爆裂和实际比分由房主决定。提示音仅在本机播放，并受静音设置控制。

## 房间状态

休息室显示连接状态、玩家外观和准备状态。房主可设置当前玩法选项；所有真人玩家准备后才可开始。设置变化会取消准备，防止玩家未确认新设置就开局。

连接等待期间可以主动离开房间。加载阶段等待本轮玩家全部确认；超时返回休息室。比赛结束后返回房间，再次调整设置或开始新局。

房间的同步和状态约束见 [联机约定](network_protocol.md)。
