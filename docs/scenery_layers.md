# 场景层与手持道具

游戏天空中不绘制太阳。休息室和后院可显示天空、云朵和远山；弗纳克球场是封闭室内场馆，不显示天空或云朵。

`ui/scene_layers.gd` 为场景创建独立绘制层：

| 节点 | 深度 | 内容 |
| --- | --- | --- |
| FarLayer | -30 | 天空、云朵与远山；球场使用封闭顶棚 |
| MiddleLayer | -20 | 墙面、窗框、围栏、地面和场馆结构 |
| NearLayer | -10 | 家具、种子车、耕地、植物和可站立平台 |

角色、比赛用球和界面位于环境层前方。背景图形不负责碰撞；修改地形时也要更新对应的移动边界、平台或家具数据。

休息室窗户与后院共享 `ui/outdoor_scenery.gd` 的天空和远景。房间墙面应为窗户保留开口，不要在中景墙面重复绘制窗外景色。

手持道具的接触位置由 `Wum.held_item_pose()` 计算，并随角色站姿、蹲姿、帽子和二段跳旋转更新。种子、作物、货币和染色泡泡属于休息室物品，不带入比赛场景。
