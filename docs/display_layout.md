# 地图与显示布局

休息室、后院和比赛地图以 1920×1080 世界坐标为基准。场景按比例适配屏幕，完整显示角色和交互区域；宽屏增加两侧场景，较窄或竖屏增加上下场景，不拉伸角色和道具。

世界相机与界面分开布局。比赛计时、比分、蓄力显示和结算面板使用屏幕空间；角色、泡泡、帽子、交互物件和背景使用世界坐标。

调整显示设置或可玩区域时，检查以下共享入口，避免绘制与碰撞不一致：

- `core/world_layout.gd`：世界基准尺寸、地图边界和缩放。
- `core/lobby_motion.gd`：休息室与后院的地面、家具落脚面和区域切换。
- `core/player_motion.gd`：比赛地形、平台落点与移动碰撞。
- `ui/smooth_follower.gd`：角色上方交互图标和圆形蓄力显示的跟随。
