# 休息室与入口

游戏启动后进入可移动的休息室。玩家可在房间中移动、跳跃、蹲下和交互；衣柜、电脑、门和后院入口连接主要功能。

- **衣柜：**购买染色泡泡和帽子。泡泡放入服饰物品栏，选中后使用才会改变颜色；已购买帽子可试戴或从物品栏穿戴。
- **电脑：**选择单人练习、本地双人或多人房间，并设置昵称、键位、音量和蓄力显示。多人房间可创建、加入、查看玩家状态和准备。
- **门：**进入吹泡泡或弗纳克球玩法。比赛时长、泥球目标分数和单人伙伴难度按模式提供相应设置；联机开局由房主在玩家准备后发起。
- **后院入口：**连接种植场景。单人和联机跟随本机玩家；本地双人可分别进入两个场景并使用分屏。

房间与家具移动边界由 `core/lobby_motion.gd` 提供，绘制由 `ui/menu_room.gd` 和场景资源负责。交互、玩家设置和房间流程入口在 `scripts/main_menu.gd`、`core/game_settings.gd` 与 `core/network_session.gd`。

本地双人设置保存在本机；同机两名玩家共享音频输出。在线昵称和外观在加入房间前设置，房间中的外观或比赛设置改变会取消该玩家的准备。
