# 泡泡随机与计分

每次开始吹气时，房主从 `modes/bubble_race/balanced_bubbles.gd` 管理的随机池中分配本颗泡泡的爆裂时限。当前范围为 1.5–4.0 秒。随机池配对平衡短、长和中等时限，限制短泡泡或长泡泡连续出现的次数；具体顺序仍会变化，不是固定轮播。

有效吹气下限为 0.3 秒。泡泡爆裂、或低于下限时松开，都会消耗该次随机分配。比赛截止时未放出的泡泡不计分。

自然进度按有效吹气时间占本颗时限的比例计算；口哨可增加当前泡泡进度，但不能替代实际吹气时间。基础精确得分为：

```text
实际吹气秒数 × 10 × (0.6 + 0.4 × 有效进度²)
```

放出进度达到 92% 时额外获得 2 分。爆裂泡泡可按贡献比例奖励口哨协助者；直接用口哨击破时，击破者获得更高份额。具体范围、减益和奖励倍率集中在 `modes/bubble_race/bubble_config.tres`。

随机序列由房主生成，并纳入恢复状态。客户端只显示房主同步的泡泡时限、进度和分数，不能自行决定结果。
