# 巫泡：休息日 · Wuppo: Day Off

当前版本：**0.35.1** · 引擎：**Godot 4.7.2** · 联机协议：**29**

《巫泡：休息日》是一款受 Wuppo 启发的 2D 休闲对战同人游戏，支持单人练习、本地双人，以及 2–4 人局域网或虚拟局域网联机。当前源码包含吹泡泡比赛、弗纳克球、交互休息室和后院种植。

本项目由社区维护，与 Wuppo 原作开发者及发行方无隶属关系。代码按根目录 `LICENSE` 授权；该许可证不授予 Wuppo 名称、角色或其他第三方内容的权利。

## 运行游戏

1. 安装 Godot 4.7.2。
2. 在 Godot 项目管理器中导入根目录的 `project.godot`。
3. 按 F5 运行项目。

Windows 用户也可以运行 `run_game.cmd`。如果 Godot 不在系统 `PATH` 中，请先设置 `GODOT` 环境变量，使其指向 Godot 可执行文件。运行 `run_two_windows.cmd` 可在本机打开两个游戏窗口，第二个窗口可加入 `127.0.0.1`。

## 玩法与联机

- 休息室可进入后院、购买帽子和染色泡泡、配置玩家设置，并从门进入比赛。
- 吹泡泡比赛支持单人电脑伙伴、本地双人和 2–4 人联机。
- 弗纳克球支持单人练习、本地双人及多人联机。
- 休息室与比赛使用移动、跳跃、二段跳、蹲下和口哨操作；默认键位可在游戏内更改。
- 联机使用 ENet / UDP 7000。房主创建房间，其他玩家连接房主的 LAN 或 VPN 地址；所有玩家需要运行相同版本。
- 后院种植、货币、库存和外观保存在本机 Godot `user://` 数据目录中，不会随源码提交。

详细规则见 [项目维护说明](docs/project_structure.md)、[联机约定](docs/network_protocol.md)、[休息室](docs/menu_room.md) 和 [后院](docs/backyard.md)。

## 项目结构

| 目录 | 内容 |
| --- | --- |
| `actors/` | 角色与可复用实体 |
| `assets/` | 图片、音频及角色和帽子资源 |
| `core/` | 移动、会话、存档、设置和比赛共用逻辑 |
| `data/` | 可配置数据和资源目录 |
| `modes/` | 泡泡比赛与弗纳克球玩法 |
| `scenes/`, `scripts/`, `ui/` | 场景、入口脚本和界面 |
| `tests/` | 玩法与网络烟雾检查 |
| `docs/` | 当前规则、协议和维护注意事项 |

开始协作前请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。跨玩法共享模块和资源维护入口见 [项目结构说明](docs/project_structure.md)。

## 注意事项

- 修改联机 RPC、快照字段或权威判定时，需要同步检查主机与客户端逻辑，并按 [联机约定](docs/network_protocol.md) 更新协议。
- 存档结构变更要保留旧存档读取能力，或明确处理兼容迁移。
- 资源旁的 `.import`、`.uid` 文件和 `.godot/` 内容由 Godot 管理；不要手工编辑或提交编辑器缓存。
- 新增或替换素材时，只提交自己创作或已获得再分发许可的内容，并在素材说明中记录来源和署名要求。
- `.godot/`、`release/`、构建目录和压缩包已由 `.gitignore` 排除。提交前请检查新增文件没有包含导出包、个人数据或未授权素材。
